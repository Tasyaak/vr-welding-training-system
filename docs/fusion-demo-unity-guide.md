# Демо Fusion: уголок 1 м, искры и остывающий шов

## Назначение и основа

Демо создано на основе `main`, коммит `6cf6c54f6c24540c58532dd7c4c829d4d1d35f21`.
Редактор: **Unity 6000.3.24f1**, URP **17.3.0**, Input System **1.20.0**.
Версии пакетов менять не требуется. Работа не привязана к Issues.

Под Fusion здесь понимается **сварка плавлением без присадочной проволоки**.
Реализован один режим: включение сварки, формирование металла и его охлаждение.
Это презентационная визуализация, а не расчёт теплопередачи, проплавления или
сертифицированная оценка качества сварки. Выраженность искр выбрана для показа.

Новый код находится в `unity/Assets/Trainer/Development/FusionDemo/`.
Старый `PrototypeWeldingDemo` и сцена `Bootstrap` остаются отдельным прототипом.
Не включайте оба контроллера демо одновременно в одной сцене.

## Быстрый запуск на компьютере

1. Откройте в Unity Hub **папку `unity` существующего репозитория**.
2. Дождитесь окончания импорта и компиляции. В Console не должно быть ошибок C#.
3. Выберите **Tools → Welding Trainer → Fusion → Create desktop presentation scene**.
4. Если Unity предлагает сохранить текущую сцену, сохраните свои изменения.
5. Генератор создаст отдельную сцену в
   `Assets/Trainer/Development/FusionDemo/Generated/FusionPresentation.unity`.
   При повторном создании Unity добавит номер к имени, существующая сцена не перезаписывается.
6. Нажмите **Play**, затем щёлкните по вкладке **Game** для фокуса клавиатуры.
7. Нажмите **F2** или экранную кнопку **Present: start in the middle**.
   Инструмент начнёт в середине, сварит правую половину, поднимется,
   вернётся в середину и сварит левую половину. Через 13 секунд проход закончится.
8. Подождите ещё 6 секунд: последняя горячая область станет серой.
9. Нажмите **R**, чтобы очистить результат и вернуть инструмент в середину.

Созданную сцену можно открывать напрямую в последующие запуски.
Генератор сохраняет материалы как обычные `.mat`-файлы со ссылками на шейдеры:
они попадут в сборку вместе со сценой без настройки Always Included Shaders.

### Ручное управление

| Клавиша | Действие |
| --- | --- |
| J / L | Движение вдоль шва в обе стороны |
| I / K | Поднять / опустить наконечник |
| U / O | Приблизить к вертикальной полке / отвести от неё |
| Space, удерживать | Сварка при нахождении в рабочей зоне |
| Left Shift | Быстрое перемещение |
| R | Сброс шва, искр и положения инструмента |
| F2 | Запуск / остановка автоматического показа со сбросом |

Обычная скорость — 0,08 м/с; с Shift — 0,3 м/с.
Начальное положение находится у середины шва, внутри уголка.
В автоматическом показе Space не требуется. Для возврата к ручному режиму
нажмите F2 или R. Клавиатура используется только при **Control Mode = Desktop**;
самопроизвольного переключения на неё при потере XR-контроллера нет.

## Что создаётся и как связано

```text
Presentation Camera                    [Camera, AudioListener; только desktop]
Key light                              [Directional Light; только desktop]
Presentation plinth                    [визуальная подставка; только desktop]
Fusion Presentation                    [FusionWeldingDemo]
├── Workpiece — 1m angle                [система координат детали, Scale = 1]
│   ├── Horizontal flange              [Cube, MeshRenderer, BoxCollider]
│   ├── Vertical flange                [Cube, MeshRenderer, BoxCollider]
│   └── Progressive fillet             [MeshFilter, MeshRenderer, FusionBead]
├── Weld effects                       [FusionSparks]
│   ├── Hot streaks                    [создаётся в Play]
│   ├── Cooling embers                 [создаётся в Play]
│   └── Pool light                     [создаётся в Play]
├── Tool tip frame                     [начало координат наконечника]
│   └── Nozzle                         [визуальная модель сопла]
└── World status                       [TextMesh, MeshRenderer]
```

Связи на компоненте **FusionWeldingDemo**:

| Поле Inspector | Что перетащить |
| --- | --- |
| Workpiece | Transform объекта `Workpiece — 1m angle` |
| Bead | `FusionBead` с `Progressive fillet` |
| Sparks | `FusionSparks` с `Weld effects` |
| Tool Visual | Transform `Tool tip frame` |
| Status Text | `TextMesh` с `World status`; можно оставить пустым |
| Control Mode | Desktop для компьютера; XR для Quest |
| Tracking Origin | Только XR: `OVRCameraRig/TrackingSpace` |
| External Tip | Только ExternalTip: существующий Transform конца инструмента |

На **FusionSparks** поле **Spark Material** должно ссылаться на
`Generated/Sparks.mat` с шейдером **WeldingTrainer/Fusion Spark**.
На **MeshRenderer** объекта `Progressive fillet` назначьте
`Generated/Bead.mat` с шейдером **WeldingTrainer/Fusion Metal**.
В режиме редактирования MeshFilter шва пустой — это нормально:
геометрия создаётся в `Awake`, видимые треугольники появляются при сварке.

Генератор назначает эти связи автоматически. Animation Controller, Animator,
Animation Clips, VFX Graph, текстуры и сторонние ассеты не требуются.

## Ручная сборка геометрии

Если хотите собрать сцену самостоятельно, сначала один раз вызовите генератор
для получения материалов либо создайте материалы с указанными выше шейдерами.

1. Создайте пустой `Fusion Presentation`, Scale **(1, 1, 1)**, добавьте
   `FusionWeldingDemo`.
2. Внутри создайте пустой `Workpiece`. Его локальное начало — внутренний корень
   шва; локальная **Z** направлена вдоль метровой детали, **X** и **Y** — внутрь
   открытого угла. Границы шва: **(0, 0, −0.5)** и **(0, 0, +0.5)**.
3. Создайте две дочерние Cube:

| Объект | Local Position | Local Rotation | Local Scale |
| --- | --- | --- | --- |
| Horizontal flange | (0.044, −0.003, 0) | (0, 0, 0) | (0.1, 0.006, 1) |
| Vertical flange | (−0.003, 0.044, 0) | (0, 0, 0) | (0.006, 0.1, 1) |

Две полки формируют уголок с наружными размерами **100 × 100 × 1000 мм**, толщина
6 мм. Внутренние плоскости — `x = 0` и `y = 0`; кубы перекрываются в толще металла.
Назначьте обеим полкам `Steel.mat` (URP/Lit, Metallic 0.8, Smoothness 0.4).

4. Добавьте дочерний `Progressive fillet`, сбросьте его Transform:
   Position **0**, Rotation **0**, Scale **1**. Добавьте `FusionBead`;
   MeshFilter и MeshRenderer добавятся автоматически. Назначьте `Bead.mat`.
5. Рядом с Workpiece, под общим корнем, создайте `Weld effects`, добавьте
   `FusionSparks` и назначьте `Sparks.mat`.
6. Создайте `Tool tip frame`. Его начало должно совпадать с концом сопла;
   локальная **+Z** указывает из сопла на деталь. Саму модель сопла расположите
   позади начала, по отрицательной Z. Не назначайте родительский XR-риг в Tool Visual:
   скрипт перемещает этот объект каждый кадр.
7. При желании добавьте TextMesh и назначьте Status Text. Поверните текст лицом
   к зрителю. Это неподвижная надпись в мире, она не следует за головой.
8. Назначьте ссылки из таблицы. Для desktop нужны также Camera, AudioListener
   и Directional Light; используйте URP, уже настроенную в проекте.

Размещать и поворачивать нужно **Workpiece целиком**, а не отдельный шов.
В созданной сцене Position = **(0, 0.95, 0)**, Rotation = **(0, 90, 0)**:
метровая ось лежит горизонтально перед зрителем, угол открыт к камере.
Масштаб Workpiece и всех его родителей должен оставаться **(1, 1, 1)**.
Длина фиксирована кодом и геометрией; масштабирование нарушит размеры в метрах.

## Подключение к существующей сцене Quest 3

1. Откройте `Assets/Trainer/Scenes/Bootstrap.unity` и сохраните копию через
   **File → Save As**, например `Assets/Trainer/Scenes/FusionQuest.unity`.
2. Оставьте один существующий `OVRCameraRig`. Не добавляйте desktop-камеру поверх
   рига; в сцене должна быть одна активная система XR-камер и один AudioListener.
3. Выберите **Tools → Welding Trainer → Fusion → Add to current XR scene**.
   Команда добавляет деталь, инструмент, эффекты и надпись, выбирает XR-режим,
   отключает компоненты старого `PrototypeWeldingDemo` в активных объектах.
   Свет и XR-риг команда не создаёт. Проверьте наличие Directional Light.
4. На `Fusion Presentation` проверьте **Tracking Origin**:
   перетащите именно **OVRCameraRig → TrackingSpace**.
   Автопоиск — лишь удобство, он рассчитан на стандартное имя объекта.
5. **Controller Tip Offset = (0, 0, 0.12)** — начальное смещение кончика в
   локальных координатах правого контроллера. Это не калибровка вашего крепления:
   отрегулируйте смещение по фактическому положению кончика.
6. Разместите Workpiece на удобной высоте и расстоянии в пределах комнаты.
   Используется фиксированная позиция сцены; деталь не появляется автоматически
   перед текущим направлением взгляда и не имеет физического QR-якоря.
7. Для MR используйте уже настроенный passthrough проекта: OVRManager со Stage
   tracking origin, Insight Passthrough и `OVRPassthroughLayer` в режиме Underlay;
   фон XR-камеры — Solid Color с альфой 0, Skybox отсутствует.
   Для полностью виртуального показа passthrough не требуется.
8. Запустите Meta Project Setup Tool и проверьте блокирующие требования Android/Quest.
   Убедитесь, что в используемом Android-профиле сохранены существующие OpenXR/Meta настройки.
9. В **File → Build Profiles → Scene List** добавьте `FusionQuest` и включите её
   первой сценой демосборки. Исключите Bootstrap из этого списка, если не нужен
   его запуск. Генератор специально не меняет список сцен проекта.
10. **Build And Run** на подключённом Quest. Подведите наконечник к внутреннему
    углу, удерживайте правый trigger. **B** сбрасывает шов; положение XR-инструмента
    при сбросе остаётся положением реального контроллера.

Если используете уже готовую систему трекинга наконечника, выберите
**Control Mode = ExternalTip** и назначьте External Tip. Ваш адаптер должен
обновлять `externalTrigger` и `externalTrackingValid` каждый кадр до Update демо
(порядок исполнения демо — 100). Без `externalTrackingValid = true` сварка запрещена.
В этом режиме смещение Controller Tip Offset не применяется.

## Настройка внешнего вида и поведения

| Компонент / поле | По умолчанию | Эффект |
| --- | --- | --- |
| FusionBead / Cells | 500 | Участки длиной 2 мм; 7000 вершин на весь метр |
| FusionBead / Leg | 0.008 м | Ширина углового шва по каждой полке |
| FusionBead / Reinforcement | 0.0012 м | Выпуклость с периодическими чешуйками |
| FusionBead / Formation Seconds | 0.12 с | Плавное нарастание профиля нового участка |
| FusionBead / Cooling Seconds | 6 с | Время перехода от красного свечения к серому металлу |
| Bead.mat / Cooled metal | Серо-стальной | Цвет остывшего шва |
| FusionSparks / Sparks Per Second | 140 | Частота длинных искр; угольки — ещё 20% |
| FusionSparks / Contact Light | Включено | Небольшая пульсирующая подсветка места сварки |
| FusionWeldingDemo / Maximum Distance | 0.025 м | Допуск расстояния наконечника от корня шва |
| FusionWeldingDemo / Maximum Bridge Distance | 0.025 м | Максимальное соединяемое перемещение между кадрами |
| FusionWeldingDemo / Maximum Sample Gap | 0.1 с | После более долгой паузы начинается новый участок |

Меняйте параметры компонентов **до Play**: геометрия, частицы и длительность
охлаждения инициализируются при запуске. Материал шва хранит цвет; времена
из FusionBead передаются через MaterialPropertyBlock и имеют приоритет над материалом.

Шов — объёмная сетка с металлическим освещением и периодическим рельефом,
а не плоская LineRenderer-полоска. Каждый участок хранит время первого появления
и последнего нагрева. Повторная сварка возвращает красное свечение, не увеличивая
процент готовности и не создавая второй слой геометрии. Нет автозавершения при
достижении конца: 100% требует покрытия всех участков.

Во время обычного непрерывного движения промежутки между кадрами заполняются.
После отпускания trigger, ухода из рабочей зоны, потери трекинга, паузы приложения
или большого скачка позиции линия не соединяется с предыдущим местом.
Рабочая область ограничена внутренним квадрантом: через обратную сторону полок
сварка не выполняется. Коллайдеры детали не используются как условие сварки:
расстояние вычисляется в системе координат Workpiece.

Частицы летят в мировых координатах и продолжают затухать после отпускания trigger.
Сброс удаляет их сразу. Коллизии частиц отключены ради стоимости на Quest:
это художественный эффект, возможен пролёт частиц сквозь деталь/подставку.
Для более яркого desktop-показа можно отдельно добавить Global Volume с Bloom;
для работы демо он не требуется. Подсветка точки зависит от поддержки Additional
Lights в выбранном URP Asset; при её отключении сами искры и свечение шва сохраняются.

## Проверка перед презентацией

1. Сварите короткий участок **в середине**. Оба конца должны остаться чистыми;
   после первого кадра процент около 0.2%, а не 50%.
2. Отпустите Space/trigger, переместитесь в другое место и сварите вторую точку.
   Промежуток не должен заполниться.
3. Пройдите участок в обратную сторону: он снова раскаляется, процент не удваивается.
4. Удерживая сварку, отведите кончик более чем на 2.5 см, затем верните в другом
   месте. Искры прекратятся; пропуск сохранится.
5. Дойдите только до одного конца: это не должно автоматически завершить весь шов.
6. Запустите F2 и дождитесь полного прохода: обе половины заполняются до 100%.
7. После прекращения нагрева дождитесь 6 секунд: свечение исчезает, остаётся серый
   рельефный металл. Ранние участки остывают раньше поздних.
8. Сбросьте R/B, повторите несколько раз: нет старых искр, шов чистый.
9. На Quest проверьте изображение обоими глазами, потерю/возврат трекинга,
   положение наконечника, повторное нажатие B и плавность эффекта.

Автоматическая проверка покрытия: **Tools → Welding Trainer → Fusion → Check coverage logic**.
Она проверяет старт с середины, повторный обратный проход, раздельные точки,
включение обоих концов и сброс. Это не заменяет проверку изображения в шлеме.

Для повторяемой генерации и проверки через командную строку (Unity должен быть закрыт):

```powershell
& 'C:/Program Files/Unity/Hub/Editor/6000.3.24f1/Editor/Unity.exe' `
  -batchmode -projectPath 'C:/Users/olegk/vr-welding-training-system/unity' `
  -executeMethod WeldingTrainer.FusionDemo.Editor.FusionDemoBuilder.GenerateAndCheck `
  -quit -logFile 'C:/Users/olegk/vr-welding-training-system/unity/Logs/fusion-validation.log'
```

Успех отмечается строкой `FUSION_CHECKS_PASSED` в журнале; дополнительно проверяйте
отсутствие ошибок C# и shader compilation. Команда создаёт новую отдельную сцену.

## Если что-то не видно

- **Нет меню Fusion**: сначала исправьте ошибки компиляции в Console, проверьте
  папку `Editor` у FusionDemoBuilder.cs.
- **Розовый материал**: убедитесь, что активна URP проекта, оба `.shader` импортированы,
  а на материалах назначены правильные шейдеры. Не заменяйте их Standard.
- **На компьютере инструмент не двигается**: выберите Desktop, дайте фокус Game;
  пакет Input System уже установлен проектом.
- **На Quest нет сварки**: выберите XR, назначьте TrackingSpace, проверьте трекинг
  правого контроллера и смещение кончика. Desktop-показ F2 в XR отключён.
- **Шов пустой до Play**: ожидаемо, сетка создаётся во время выполнения.
- **Шов заготовки находится отдельно**: Progressive fillet должен быть дочерним
  Workpiece с нулевыми Position/Rotation и единичным Scale.
- **Текст смотрит в другую сторону**: поверните World status к месту зрителя.
- **Шов слишком тёмный после остывания**: проверьте Directional Light и ambient
  lighting; светящийся красный шов виден даже при отсутствии нормального освещения.
- **Скачки дают разрывы**: это защита от соединения несвязанных позиций. Для быстрого
  движения сначала проверьте частоту кадров и трекинг, затем настройте Bridge Distance.
